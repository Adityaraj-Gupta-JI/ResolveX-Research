# Roadmap — v0.1

No fixed calendar dates. Milestones are capability-based.

## M0: Mathematical kernel
Finalize PCP residual semantics, restricted while-language, result schemas, independent witness checker, first TLA+ models, executable Rust CLI and tests.

## M1: Working research application
Interactive editors and state graphs, both engines, reproducible benchmark runner, ten benchmark categories, data export and proof inspector.

## M2: Advanced research
Sound UNSAT certificate families, invariant synthesis, SMT-backed obligations, rigorous comparisons with baselines, optional heuristic/AI guidance and deeper mathematical visualizations.

## Release gate
No public release labeled as a functioning solver until at least one PCP and one termination case execute correctly, are tested, and have accurately described verification scope.
