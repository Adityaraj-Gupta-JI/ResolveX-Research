# Project Vision — v0.1

## Identity
**ResolveX — Proof-Guided Analysis of Correspondence Problems and Program Termination**

**Tagline:** Explore the Unknown. Prove the Possible.

## Mission
Build an experimentally reproducible and mathematically honest environment for investigating computation, undecidability boundaries, symbolic state spaces, and proof-guided analysis.

## Research questions
- RQ1: Which sound residual-state abstractions and pruning rules improve PCP search efficiency?
- RQ2: Which useful restricted PCP families admit automatically checkable negative certificates?
- RQ3: How do ranking functions, inductive invariants, and recurrent sets perform on restricted imperative programs?
- RQ4: Can guided search improve performance without affecting the soundness of certified conclusions?

## Principles
Correctness over presentation; verified claims over predictions; unknown over unsupported rejection; reproducibility over screenshots; separation of mathematical specification, implementation, and certificate checking.

## Scope
Two computational engines in one research application, with shared experiment orchestration and visualization. General PCP and the Halting Problem remain undecidable.

## Current status
Planning and repository scaffold only. No original theorem or experimental superiority has been established.
